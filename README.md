# RLK Walking Tour

Begleitseite zur Walking Tour des [Reiner Lemoine Kollegs](https://www.reiner-lemoine-stiftung.de/kolleg/): sechs Stationen in Berlin-Neukölln und Kreuzberg, an denen Promovierende des Kollegs ihre Forschung zur Energiewende erklären — live unter [kafu16.github.io/rlk-walking-tour](https://kafu16.github.io/rlk-walking-tour/).
